# 演示媒体说明

案例：语音快捷键盘外壳与产品模型。

- `keyboard-assembly.png`、`keyboard-exploded.png`：来自 v15a 封排针孔版本设计工程，分别为完整装配和结构分解渲染。
- `keyboard-exploded.mp4`：2026-10-27 产品展示工程的 10 秒拆装片段；转码为 1280×720、H.264、静音，保留原速。
- `preview.gif`：同一片段的 640 像素宽、8 FPS 静音预览。

静态设计图与动态产品展示属于同一产品的不同表现版本，外观、键帽、材质和装配状态可能不同，不应混用为同一版尺寸依据。展示渲染不代表实物打印、配合或强度验证。

这些是项目方法案例；仓库附带生成器运行的是独立参数化盒壳示例，不会直接生成键盘模型。公开仓库只加入预览媒体，原始 CAD、实际 PCB 和私人制造资料未包含。
