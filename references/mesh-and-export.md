# 网格、数值与导出

标准 binary STL 按 84+50×面数与文件长度一致识别，不能仅凭 solid 头。ASCII 与 binary 均拒绝 NaN/Inf。ASCII 解析为 float64；binary 原始 float32 转 float64 不能恢复损失精度。STL 的单位需显式声明。

观察坐标范围、最小边、最小高、长宽比、float32 ULP 和量化后退化。远离原点降低小特征分辨率；归零应记录为派生导出变换，不覆盖装配基准。ULP 不是制造精度，极瘦面也可能非零面积；没有适用标准时不把单一阈值当万能合格线。

边被两面使用不能证明完整合格。分别报告边连接、定向一致性、分量、零面积、序列化法向与几何法向、体积和量化退化。自交、顶点流形、全局壁厚、完整碰撞、强度和可打印性需额外算法或试验；基础脚本保留 not_established，不扩大结论。

只读诊断不自动焊接、翻面或修复。容差焊接是修复，需保留前后文件、参数、尺寸和偏差。平台提示未本地复现时，不能把猜测写成已定位根因。

保存源工程、装配坐标、打印变换、无支撑原件；导出后回读每件，核对尺寸与网格，而非只检查导出前源网格。平台限尺、AABB 或凸包摆向搜索，不等于工艺、费用资格或尺寸审核通过。Blender 网格导出不是精确 B-rep/STEP 转换。
