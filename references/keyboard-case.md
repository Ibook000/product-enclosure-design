# 键盘外壳案例

可靠方法来自真实板框、器件功能轴线、用户实测屏幕和统一装配基准。导入模型原点可能与 PCB 轴线不一致，修正应记录，不移动真实 PCB 迁就错误模型。

检查屏幕净窗与入口、插头包胶、按键旋钮行程；区分 nominal、微小运动、侧止挡、去盖拆卸和合盖捕获。圆角要看实际截面，试孔/卡合片确认具体工艺配合。

源支撑独立且保留无支撑原件；上传需单体时另做合并版本。导出回读尺寸与网格，旧 STL 不随源工程自动更新。

本案出现过非零面积仍有瘦三角形、平台提示本地未复现、局部厚度和全局结论不同的问题。通用检查分别报告范围，不把局部结果提升为完整可打印验收。

板尺寸、键数、孔径、树脂、拆装距离与支撑方向均为案例参数。本技能不包含原始 CAD、实际 PCB 或私人生产资料。
